About this bot

Small, reviewable, and interview-friendly

This is a study aid powered by Claude via the Anthropic API. It is helpful for short refreshers, but it is not authoritative guidance or an operational response system.

  • Scopes answers to SOC terminology and analyst workflow concepts
  • Uses a constrained system prompt that refuses attack guidance
  • Stores chat history in browser localStorage so local demos work without a database

API source: Anthropic Messages API
